Ensemble methods
================

Ensembles of ordinal models. ORBoost boosts a projection with ordered
thresholds, and OrdinalXGBClassifier boosts XGBoost trees with an ordinal
threshold objective. OPBE, the ordinal projection-based ensemble, fits one
model per fixed subproblem and is documented with the reductions.
